# LaslesVPN Landing Page

A responsive landing page for LaslesVPN, built with HTML and SCSS based on a Figma design.


## Features

- Responsive layout for desktop, tablet, and mobile screens.
- Navigation links to different sections of the page.
- Pricing plans and customer testimonials sections.
- Hover effects and transitions for interactive elements.


## Technologies & Concepts

- HTML5
- SCSS (Sass), including variables, nesting, and BEM naming conventions.
- CSS Variables
- Flexbox and CSS Grid
- Media Queries
- CSS Transitions and Hover Effects
- CSS `:checked` and `:has(:target)` for CSS-based interactions.
- CSS `scroll-snap` for scrolling through testimonial cards.
